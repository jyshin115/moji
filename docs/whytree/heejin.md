## 씨앗 (팀이 실제로 하는 일 다섯 가지)

1. 사업장 정보 입력
2. 공고 수집
3. 자격 조건 추출
4. 가능 공고 안내·알림
5. 사업계획서 초안

## 수렴 지점

다섯 가지 일이 모두 "5인 미만 대표가 대행 없이 혼자 신청 끝내기"로 모인다.
그래서 이 트리의 핵심 가치는 **공고를 많이 보여주는 것이 아니라,
틀리지 않게 안내하고 신청까지 이어지게 하는 것**이다.

## 내 premortem에서 가져온 것 (내가 직접 대조해서 고칠 부분)

- HW5 premortem에서 나는 두 가지를 인정했다.
  첫째, 사용자를 "중소기업"이라고 넓게 잡은 채 입력 항목부터 정했다.
  둘째, 텍스트가 추출되면 파싱이 됐다고 봤다.
- 그래서 이 트리에서는 타깃을 5인 미만 영세사업장 대표로 좁혔고,
  "조건·예외·표 유지 파싱"을 새로 찾은 방법으로 넣었다.
  "불확실하면 추가 확인 필요" 원칙은 트리가 아니라 스펙의 판정 규칙으로 넣었다.
