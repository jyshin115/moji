## 구현 범위

- **P0 완료**: 4개 필드 입력 → AND 매칭 → 가능 상단 / 불가 하단 + 미충족 사유 전부 표시
- **P1 완료**: D-day 배지, 마감임박(7일 이내) 강조, 마감됨 처리, 모바일 대응
- **P2 (범위 밖)**: 공고 자동 수집, 알림 발송, 입력 저장, 초안 연계

## 구현 후 스펙에서 바뀐 것

- 불가 사유를 "첫 번째 하나"가 아니라 **전부** 나열하기로 한 결정이 구현에서 실제로 의미 있었다
  (근로자 7명 + 경기도 공고 조합에서 사유 2개가 동시에 표시됨).
- 신청 가능 공고 정렬 기준을 스펙에 안 정했던 것을 구현 중 발견 → **마감 급한 순**으로 정렬 추가.
