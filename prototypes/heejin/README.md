# 프로토타입: 신청 가능 여부 판정·마감 알림 (heejin)

스펙: `docs/specs/heejin-eligibility.md`의 P0 범위만 구현했다.

## 실행 방법

1. `index.html`을 브라우저에서 연다. (서버, 설치, API 키가 필요 없다.)
2. 사업장 정보를 입력하고 "판정하기"를 누른다.
3. 아래 수동 테스트 3개를 순서대로 한다.

## 수동 테스트 (스펙 7절과 동일)

1. **해당 없음 제외**: 지역을 서울로 두고 부산 전용 샘플 공고를 확인한다.
   "해당 없음"으로 표시되고 신청 가능 목록에 나오지 않아야 한다.
2. **마감 임박 알림**: 마감이 7일 이내인 신청 가능 공고가
   "마감 알림 큐"에 뜨는지, 지난 공고는 뜨지 않는지 확인한다.
3. **불확실하면 확정 안내 금지**: 업종을 제조로 두면 "제조 소공인 설비 지원"이
   "확인 필요"로 표시되고, 되묻는 질문이 뜨는지 확인한다.
   답하기 전에는 "신청 가능"으로 바뀌지 않아야 한다.

## 정직한 범위

- 공고 5건은 전부 샘플이다. 실제 공고·실제 API가 아니다.
- 판정은 규칙(업종·지역·업력·매출·상시근로자 수)만 한다.
  첨부문서 AI 추출은 P1이며, 이 프로토타입에는 없다.
- 데이터는 메모리에만 있다. 새로고침하면 사라진다.
- 선정 가능성 예측·순위 추천은 하지 않는다 (PROJECT.md 기준).

## 보안

- 이 폴더에는 API 키, `.env`, 개인정보, 실제 사업자 데이터가 없다.
- 팀 저장소에 올릴 때 `.gitignore`에 `node_modules/`와 `.env`가 있는지 먼저 확인한다.
