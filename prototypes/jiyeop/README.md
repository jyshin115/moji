# MOJI 지원사업 찾기 — HW6 신지엽

## 실행

저장소를 내려받은 뒤 이 폴더의 `index.html`을 브라우저로 연다. 설치·서버·API 키가 필요 없다. `data.js`, `matcher.js`, `app.js`를 같은 폴더에 유지한다. GitHub의 파일 화면 자체에서는 앱이 실행되지 않는다.

P0는 수록 공고 10건의 기본 조건만 비교한다. AI 설명과 자동 수집은 P1이다. 입력은 저장하거나 전송하지 않는다. 수록 조건 외의 상세 자격은 원문에서 확인한다.

- 명세: [jiyeop-grant-finder.md](../../docs/specs/jiyeop-grant-finder.md)
- WhyTree: [jiyeop.md](../../docs/whytree/jiyeop.md)
- 출처: `data.js`의 각 기업마당 공식 원문 링크, 확인일 2026-10-27. 첨부 원문 전체는 미검토.

## 사용자 직접 검사 — 2026-10-27 통과

‘확인용 입력: 봉화 소매점’은 기준일이 2026-10-27인 검증 모드로 전환한다. 오늘의 모집 상태를 나타내지 않는다.

1. 예제 입력 → 후보 찾기 → 봉화 카드수수료 공고 확인. 매출 20000만원을 40000만원으로 바꾸면 해당 공고 제외.
2. 매출을 비우면 같은 공고에 ‘매출액 확인 필요’ 표시.
3. 소상공인 ‘해당하지 않음’이면 결과 없음, ‘해당’으로 복구하면 후보 표시. 스마트상점 공고는 마감으로 제외되며 원문 링크가 열리는지 확인.

사용자가 직접 수행한 결과만 회고에 적는다. 에이전트 자동 검사로 대체하지 않는다.

사용자 보고: 첫 번째 검사 수행 후 ‘응 전부 실행됐어’, 두 번째·세 번째 검사 안내 후 ‘전부 통과’. 위 세 검사와 원문 열기를 모두 통과했다. 보고된 실패나 추가 코드 변경은 없다.

## 에이전트 자동 검사

Node.js가 있는 환경에서 `node --test prototypes/jiyeop/matcher.test.js` 실행. 매출 경계, 빈칸/0, 불일치 우선, 마감/접수일, 결과 없음과 복구, 예산 소진, 직원 수, 한국 날짜 및 출처 링크를 검사한다.

2026-10-27 에이전트 실행 결과: 9개 통과. 브라우저에서 예제 검색, 매출 초과 제외, 매출 미입력 안내를 확인했다. 이후 사용자도 위 직접 검사 3개를 통과했다고 보고했다.
