# 프로토타입: 세무 자료로 사업장 정보 자동 채우기 (chanyang)

스펙: `docs/specs/chanyang-taxprefill.md`의 P0 범위만 구현했다.
AI는 쓰지 않는다 (P0는 규칙 기반, 스펙 6절).

## 실행 방법

1. `index.html`을 브라우저에서 연다. 서버, 설치, API 키가 필요 없다.
2. 스펙의 기대값은 2026-10-29 기준이다. 다른 날 확인할 때는 주소 끝에 `?today=2026-10-29`를 붙인다.
3. 샘플 사업장 3곳은 모두 합성 데이터다. 실제 거래처 자료가 아니다.

## 손으로 하는 확인 (스펙 7절과 같음)

1. **정상 사업장 값이 손계산과 같다**
   - 동의 체크 전에는 값이 보이지 않는다.
   - A 골목식당: 음식점 / 서울 / 43개월 / 2.2억 / 3명.
   - 상시근로자: 2+2+3+3+3+3+4+4+4+3+3+3 = 37, 37÷12 = 3.08 → 3명.
2. **없는 자료를 0으로 채우지 않는다**
   - B 동네꽃집: 상시근로자 칸이 빈칸이고 "확인 필요"다.
   - "이대로 확인" 버튼이 눌리지 않고, 남은 칸이 표시된다.
3. **출처가 맞고 수정이 반영된다**
   - C 바른수학학원: 연매출 출처가 "2025 사업장현황신고 수입금액"이다.
   - 연매출을 2.0으로 고치면 출처가 "대표 수정"으로 바뀐다.
   - "이대로 확인"을 누르면 JSON의 `sales`가 2.0이다.
